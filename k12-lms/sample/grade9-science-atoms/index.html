Lesson

Atoms, Elements & the Periodic Table

Everything around you — the air, water, your own body — is made of tiny particles called atoms. In this lesson you will look inside an atom and learn how scientists organise every known element.

By the end you will be able to

  1. Describe the three subatomic particles and their charges.
  2. Use atomic number and mass number to count protons, neutrons and electrons.
  3. Explain what isotopes are.
  4. Draw the electron shell arrangement for the first 20 elements.
  5. Read groups and periods on the periodic table.

Part 1

Inside the atom

An atom has a tiny, dense nucleus at its centre, surrounded by mostly empty space where electrons move.

In a neutral atom the number of electrons equals the number of protons, so the charges cancel out.

Part 2

Atomic number & mass number

Atomic number (Z) = number of protons. It identifies the element — every carbon atom has 6 protons.

Mass number (A) = protons + neutrons.

neutrons = A − Z

Worked example: chlorine-35

Z = 17, A = 35 → protons 17, neutrons 35 − 17 = 18, electrons (neutral) 17.

Isotopes

Isotopes are atoms of the same element with different numbers of neutrons. Carbon-12 (6 neutrons) and carbon-14 (8 neutrons) are both carbon because both have 6 protons. Carbon-14 is radioactive and is used to date ancient remains.

Part 3

Electron shells

Electrons fill shells from the inside out. For the first 20 elements the shells hold up to 2, 8, 8 and then the next electrons start a 4th shell.

ElementElectronsArrangementValence electrons
Hydrogen (H)111
Carbon (C)62, 44
Oxygen (O)82, 66
Sodium (Na)112, 8, 11
Chlorine (Cl)172, 8, 77
Calcium (Ca)202, 8, 8, 22

The electrons in the outermost shell are called valence electrons. They decide how an element reacts.

Part 4

The periodic table

Elements are arranged in order of atomic number. Rows are periods (the number of shells). Columns are groups — elements in a group have the same number of valence electrons, so they behave alike. Tap an element.

Wrap-up

Summary

  • Atoms contain protons (+), neutrons (0) and electrons (−).
  • Atomic number = protons; mass number = protons + neutrons.
  • Isotopes have the same protons but different neutrons.
  • Electrons fill shells 2, 8, 8…; valence electrons control reactivity.
  • Periods = rows (number of shells); groups = columns (same valence electrons).
